# NHS Healthcare Management Database

## Project Overview

I built a relational healthcare database using MySQL to manage and analyze patients, doctors, departments, appointments, diagnoses, treatments, prescriptions, and payments.

## Tools Used

* MySQL
* MySQL Workbench
* SQL

## Key SQL Skills

* Database and table creation
* Primary and foreign keys
* Data insertion
* JOINs
* GROUP BY and HAVING
* Aggregate functions
* CASE statements
* Subqueries
* Common Table Expressions (CTEs)
* Healthcare and financial analysis

## Analysis Performed

The project analyzes healthcare operations and financial performance, including:

* Patient and appointment activity
* Department performance
* Doctor workload
* Appointment outcomes
* Revenue
* Insurance coverage
* Patient payments

## Project Objective

To demonstrate practical SQL, relational database design, and data analysis skills using a realistic healthcare management scenario.
