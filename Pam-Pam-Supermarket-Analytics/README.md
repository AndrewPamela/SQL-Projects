# Pam Pam Supermarket Database & Sales Analytics

## Project Overview

This project involved building and analysing a **Pam Pam Supermarket relational database using MySQL**.

The database was created and populated using SQL, followed by business-focused analysis of sales, customers, products, employees, transactions, and overall supermarket performance.

The project demonstrates practical SQL skills in database creation, data population, querying, aggregation, joins, filtering, and business analysis.

## Project Objectives

The analysis focused on understanding:

* Sales performance
* Customer purchasing behaviour
* Product performance
* Employee performance
* Transaction trends
* Key business performance indicators

## Database Development

I created and populated the supermarket database using SQL.

Key tasks included:

* Creating relational database tables
* Defining primary and foreign keys
* Inserting records using `INSERT INTO`
* Structuring data for analysis
* Writing SQL queries to extract business insights

## SQL Analysis

The project demonstrates the use of:

* `SELECT`
* `WHERE`
* `ORDER BY`
* `GROUP BY`
* `HAVING`
* `JOIN`
* Aggregate functions such as `SUM()`, `COUNT()`, and `AVG()`
* `CASE` statements
* Date functions
* Data filtering and sorting

## Business Insights

The SQL analysis was designed to identify important patterns in supermarket operations, including high-performing products, customer activity, sales trends, and employee performance.
