# Healthcare Analytics — MySQL Project

## Project Overview

This project demonstrates the design and analysis of a relational healthcare database using **MySQL**.

The database was created to simulate a healthcare environment and contains information relating to patients, doctors, departments, appointments, diagnoses, treatments, prescriptions, and payments.

The goal of the project was to use SQL to organize healthcare data and generate meaningful insights that could support operational and management decisions.

## Tools Used

* MySQL
* MySQL Workbench
* SQL

## Database Structure

The database contains several related tables, including:

* Patients
* Doctors
* Departments
* Appointments
* Diagnoses
* Treatments
* Prescriptions
* Payments
* Insurance

The tables are connected using **Primary Keys and Foreign Keys** to create a relational database structure.

## Business Questions Answered

The SQL analysis explores questions such as:

* How many patients are registered?
* Which departments handle the most appointments?
* Which doctors see the most patients?
* What is the appointment completion rate?
* Which diagnoses are most common?
* How much revenue is generated?
* How much is covered by insurance?
* How much is paid directly by patients?
* Which payment methods are most frequently used?
* Which patient age groups have the highest healthcare activity?

## Project Goal

The purpose of this project is to demonstrate how SQL and relational databases can be used to transform raw healthcare data into structured information and actionable business insights.
